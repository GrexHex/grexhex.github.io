eforce security.

a security operations platform for requests, alerts and response.

eforce security brings panic alerts, live responder tracking, dispatch, a cctv wall, incident management and multi-site reports into one place, with a provider marketplace and admin tools.

it runs in an offline demo mode or live against supabase with row-level security. built with vue 3, typescript, vite, pinia, tailwind and leaflet.
